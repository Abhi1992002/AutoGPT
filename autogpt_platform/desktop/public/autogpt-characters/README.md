# AutoGPT characters

Otto and the expert characters from the AutoGPT platform's managed library
([Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT/tree/dev/autogpt_platform/frontend/public/autogpt-characters),
branch `dev`, see its `manifest.json`). Only the 128 and 256 px WebP tiles the desktop app renders are copied here,
in the upstream folder layout. `src/assets/avatars/index.ts` maps them to names; `src/components/AgentAvatar.tsx` renders them.
